02 — Attempt 1 · Zero-shot

เริ่มด้วยคำสั่งสั้น ๆ

ZERO-SHOT
ช่วยเขียนโค้ดเกม 2D ด้วย HTML, CSS และ JavaScript ให้ผู้เล่นควบคุมตัวละครเพื่อเก็บเหรียญและหลบสิ่งกีดขวาง มีคะแนน มีพลังชีวิต และแสดงข้อความเมื่อชนะหรือแพ้ ขอให้เปิดเล่นได้ในเว็บเบราว์เซอร์

ยังไม่มีตัวอย่างโค้ด ไม่มีโครงสร้างฟังก์ชัน และไม่มีกรณีทดสอบ

06 — Game mathematics

ความสัมพันธ์ที่ทำให้
เกมขยับได้

COIN RUNNER MODEL

จากพิกัดและความเร็วสู่ Collision

ตำแหน่งใหม่เกิดจากตำแหน่งเดิม ความเร็ว และช่วงเวลาในแต่ละเฟรม

xt+1=xt+vxΔt
yt+1=yt+vyΔt

Input: WASD / Arrow keys → Update: เปลี่ยน x,y → Collision: ตรวจกรอบทับซ้อน

ผลลัพธ์: เก็บเหรียญเพิ่ม Score และชนสิ่งกีดขวางลด Lives
