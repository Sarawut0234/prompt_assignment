# Prompt Lab — Game Systems

เว็บไซต์นำเสนอการพัฒนา Prompt สำหรับการโปรแกรมมิ่งโค้ดระบบเกม โดยใช้กรณีศึกษาเกม 2D Coin Runner

## เปิดดูเว็บไซต์

ไฟล์ `index.html` ที่ระดับรากของ Repository คือหน้าเว็บไซต์หลักสำหรับ GitHub Pages ภายในมีหน้าเนื้อหาและหน้า Slides แยกอยู่ในไฟล์เดียวกัน สามารถกดปุ่ม “เปิดสไลด์นำเสนอ” เพื่อเข้าสู่โหมดสไลด์ได้

## เนื้อหาหลัก

เว็บไซต์ครอบคลุม Zero-shot Prompt, ผลลัพธ์แรก, Few-shot Prompt, ผลลัพธ์ใหม่, การสะท้อนการเรียนรู้, Mermaid Diagram, สมการคณิตศาสตร์, บทความจาก LaTeX และภาพประกอบ

## ไฟล์ประกอบ

โฟลเดอร์ `artifacts/` เก็บไฟล์ต้นฉบับและเวอร์ชันประกอบทั้งหมด ส่วนไฟล์ที่จำเป็นสำหรับการเปิดหน้าเว็บถูกคัดลอกไว้ที่ระดับรากเพื่อให้ GitHub Pages ใช้งานได้โดยตรง
